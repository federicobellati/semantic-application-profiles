Controlli del modulo

I controlli leggono le shape integrate: obbligatorietà, cardinalità, IRI, valori fissi, tipi, lingua e lunghezza minima. La presenza dell’intestazione amministrativa è controllata anche nel modulo. Per un rapporto SHACL completo usa un validatore SHACL con il file del profilo, che include un vincolo SPARQL.

Il primo risultato riguarda il Turtle generato dai dati attuali. Il report «File originale» riguarda il file caricato prima delle modifiche e dell’applicazione dei valori fissi.
